# 4주 개인 프로젝트 — 보증금 반환 타임라인 관리 서비스 (기획서 v3)

## 1. 프로젝트 주제
**보증금 반환 타임라인 관리** — 전월세 세입자가 계약 만료/갱신/보증금 반환과
관련된 법적 기한을 놓치지 않도록, 개인화된 일정 알림과 공식 정보 링크를
제공하는 **일정관리 서비스** (확정, 변경 불가)

## 2. 문제 정의 (v3.1)

**타겟**: 자취 경험이 적은 사회초년생·대학생 세입자

**배경**: 최근 전세사기 이슈가 뉴스에 자주 나오는데, 실제로 피해자의 상당수가
40세 미만 청년층이라는 조사 결과도 있다. 청년층이 전세 관련 문제에 특히
취약할 수 있다는 걸 보여준다.

> 참고: 이 통계는 "나이" 기준 데이터이고(2026년 기준 40세 미만 청년층이
> 전체 피해자의 76.0% — 국토교통부 실태조사), "자취 경험이 적어서 놓친다"는
> 건 통계가 직접 증명한 사실이 아니라 우리 팀이 세운 가설이다. 둘을 분리해서
> 명시한다.

**핵심 문제**: 사실 꼭 사기를 당하지 않아도, **정상적으로 계약이 진행되는
중에도** 세입자는 계약갱신청구권 행사 기한이나 보증금 반환 관련 절차 같은
걸 스스로 챙기기 쉽지 않다. 계약을 처음 해보거나 한두 번밖에 안 해본 사람은
"이맘때쯤 뭘 챙겨야 하는지" 감이 없고, 물어볼 사람도 마땅치 않기
때문이다(가설). 정보는 법무법인 블로그 등에 이미 많지만, **본인 계약에 맞춰
자동으로 일정을 알려주는 개인화된 도구는 없음**

**놓쳤을 때 생기는 일**:
1. **갱신 기한을 놓친 경우** — 원치 않는데도 묵시적으로 계약이 2년
   연장되거나, 반대로 나가려던 타이밍을 놓쳐 곤란해진다.
2. **보증금 미반환 시 순서를 놓친 경우** — 임차권등기명령 없이 이사부터
   가버리면 나중에 보증금 받기가 더 까다로워진다.

## 3. 시장 조사 요약
- 정부(전세피해지원센터, HUG 등): **사후 대응/피해자 지원** 중심
- 민간(ClickUp 등): 전부 **기업용** 계약관리 툴
- **세입자 개인용 계약 타임라인/체크리스트 도구는 확인되지 않음** → 빈틈으로 판단

## 4. 핵심 방향 전환: "조언자"가 아닌 "일정관리자"

기획 초기에는 앱이 법적 판단까지 내려주는 "조언자" 역할을 하려 했으나,
아래와 같은 이유로 역할을 재정의함:

| 문제 | 원인 |
|---|---|
| 날짜 계산 하나에도 법 조문 해석 리스크 발생 | 법률 자문에 해당하는 판단을 앱이 직접 내림 |
| 보증보험 가입 여부, 갱신청구권 이력 등 분기가 계속 늘어남 | 사용자별 법적 상황을 앱이 다 판단하려 함 |
| "법률 자문 아님" 고지 등 법적 리스크 부담 | 4주 개인 프로젝트로 감당하기 무거운 역할 |

**전환 방향**: 앱은 "언제"(타이밍)만 정확히 알려주고, "어떻게"(법적 판단·절차)는
검증된 공식 출처로 연결한다. → 법적 해석 부담 최소화 + 실질적 도움 유지

## 5. 핵심 기능 (주 기능 2개)

### 기능 1. 계약 정보 입력 & 자동 타임라인 생성
- 계약 시작일·만료일 + **보증금 액수** 입력 (**전세/월세/반전세 구분 없이** 동일 로직 적용, 월세는 월 임대료 선택 입력)
- 아래 항목이 자동 계산되어 개인 타임라인으로 표시
  - 만료 6개월 전 / 2개월 전 (갱신 의사표시 마지노선)
  - 만료일
  - 전세보증금반환보증 가입 마감 시점 (계약 기간 절반 경과 전, 보증금이 있는 모든 계약에 적용)

### 기능 2. 갱신 결정 알림 + 공식 링크 연결
- 만료 6개월 전, "갱신하시겠어요, 나가시겠어요?" 알림
- 선택에 따라 **찾기쉬운 생활법령정보(easylaw.go.kr)** 관련 페이지로 연결
- 통보 완료 여부와 날짜만 기록 (판단·조언은 하지 않음)

## 6. 서브 기능 (하위, 시간 남으면 추가)

### 기능 3. 미반환 대응 체크리스트 + 공식 링크 연결
- 만료일에 "보증금 받으셨나요?" 확인
- 미반환 시 "이사보다 임차권등기명령이 먼저"라는 원칙만 안내
- 아래 공식 사이트로 연결하는 버튼 제공 (판단은 각 기관에 맡김)

| 상황 | 연결 사이트 |
|---|---|
| 갱신청구권 행사, 일반 법률정보 | 찾기쉬운 생활법령정보 (easylaw.go.kr) |
| 임차권등기명령 신청 | 대법원 전자소송 (ecfs.scourt.go.kr) |
| 무료 법률상담·소송 지원 | 대한법률구조공단 (klac.or.kr), 법률구조 플랫폼 (helplaw24.go.kr) |
| 전세사기 피해자 전용 지원 (중위소득 125% 이하 등) | HUG 전세사기예방센터 (khug.or.kr/jeonse) |

> 참고: 임차권등기명령은 확정일자·주민등록 이전이 안 되어 있으면 그것부터
> 먼저 해야 하며, 등기 완료 전에 이사·전입신고를 옮기면 대항력을 잃을 위험이
> 있음 — 이 주의사항은 링크와 함께 텍스트로 안내.

## 7. 사용자 시나리오 (구체화 최종본)

### 1단계 — 계약 정보 입력
- 세입자가 앱을 처음 켠다
- 계약 시작일·만료일을 입력한다 (달력 UI)
- 입력 완료 시 타임라인 화면으로 이동

### 2단계 — 타임라인 확인
- 아래 항목이 자동 계산되어 표시됨
  - 만료 6개월 전 (갱신 결정 시점)
  - 만료 2개월 전 (통보 마지노선)
  - 만료일
  - 보증금반환보증 가입 마감일
- 세입자는 전체 일정을 한눈에 파악하고 앱을 닫는다 (평소엔 별다른 조작 없음)

### 3단계 — 갱신 결정 알림 (만료 6개월 전)
- 푸시 알림: "계약 만료가 6개월 남았어요. 계속 사실 건가요?"
- 선택 화면: **[갱신할래요] / [나갈래요]**

#### 3-A. [갱신할래요] 선택 시
1. 통보 방법 안내: 문자/카톡/내용증명 등 방법별 장단점 간단 소개
2. "자세히 알아보기" → 생활법령정보(easylaw.go.kr) 링크
3. 통보 방법 선택: [문자·카톡] / [내용증명] / [직접 얘기]
4. 증빙 보관 안내 (캡처·문자 내역 보관 추천, 저장 기능은 없음)
5. **통보 완료 체크 + 날짜 자동 기록**

#### 3-B. [나갈래요] 선택 시
1. 통보 타이밍 안내: "만료 2개월 전까지 의사표시해야 묵시적 갱신 안 됨"
2. "자세히 알아보기" → 생활법령정보 링크
3. 나갈 때 주의사항 체크리스트
   - [ ] 보증금 받기 전 전입신고 이전하지 않기
   - [ ] 새 집 잔금일 ↔ 이 집 보증금 수령일 조율
   - [ ] 등기부등본 재확인 (근저당 변동 여부)
4. 통보 방법 선택: [문자·카톡] / [내용증명] / [직접 얘기]
5. **통보 완료 체크 + 날짜 자동 기록**

### 4단계 — 미체크 시 리마인드 (만료 2개월 전)
- 6개월 알림에 응답 안 했으면, 2개월 전 시점에 재알림: "아직 통보 안
  하셨네요, 서두르세요"
- *("몰라서"가 아니라 "알아도 미뤄서" 놓치는 경우를 커버하는 지점*

### 5단계 — 만료일, 반환 여부 확인
- 알림: "보증금 받으셨나요?" → **[받았어요] / [아직이에요]**
- 받았어요 → 타임라인 종료, 기록 보관함 이동
- 아직이에요 → 6단계 (서브 기능)로 진입

### 6단계 — (서브 기능) 미반환 대응
- "이사보다 임차권등기명령이 먼저예요" 경고 + 체크리스트
- 각 항목마다 공식 링크: 대법원 전자소송 / 대한법률구조공단 / HUG 전세사기예방센터
- 완료 체크 시 기록 저장

### 7단계 — 기록 보관
- 지난 통보 날짜, 완료 여부 등을 보관함에서 언제든 다시 확인 가능

이 흐름에서 자연스럽게 도출되는 화면:
- 입력 화면 (계약 정보)
- 타임라인 화면 (전체 일정 한눈에)
- 선택/알림 화면 (갱신 vs 퇴거, 반환 여부)
- 안내/체크리스트 화면 (통보 방법, 주의사항, 미반환 대응)
- 링크 연결 화면 (공식 사이트 버튼)
- 기록 보관 화면 (지난 기록 보기)

## 8. 알려진 한계 (4주 범위에서 제외, 문서로만 명시)

- 계약갱신청구권을 이미 사용한 경우(2회차 이후) 분기 로직 없음
- 임대인이 먼저 갱신거절·증액을 통보하는 역방향 시나리오 미반영
- 공동 계약자(2인 이상) 케이스 미반영, 1인 사용자 기준
- 법 개정 시 하드코딩된 날짜 계산 로직이 즉시 반영되지 않을 수 있음
- 개인정보(계약서, 주소, 보증금 액수) 보안/프라이버시 처리 방침 별도 수립 필요
- "법률 정보 제공일 뿐 법률 자문이 아니다"라는 면책 고지 — **설정/정보
  페이지("이 앱에 대하여")에 상시 배치**. 문구: "이 앱은 법률 자문이 아닌
  일정 안내 서비스입니다. 정확한 법적 판단은 공식 기관이나 전문가를 통해
  확인해주세요." (다른 화면에는 반복하지 않음)

### 향후 확장 아이디어 (이번 4주 범위에는 포함하지 않음)
- 전기세·수도세·관리비 등 생활비 관리 기능 — 문제 유형이 완전히 다르고
  (주기적/저위험 vs 이벤트성/고위험), 이미 포화된 시장(가계부 앱 등)이라
  이번 프로젝트 스코프에서는 제외하고 아이디어로만 남겨둠
